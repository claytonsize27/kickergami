# NFL Official Partial 1970-1998 Source Notes

This upload CSV is intentionally partial. The app requires exact made field-goal distances per kicker game. Official NFL.com player game logs provide game-level FGM, FGA, XPM, XPA, and long made field goal, but they do not list every made field-goal distance when a kicker made multiple field goals. Therefore, rows were included only where an NFL-hosted game summary PDF exposed the full made/missed field-goal list.

Primary official sources used:

- NFL.com player stats pages expose field-goal seasons back through 1970, including 1998 season aggregate leaders.
- NFL.com player game logs expose per-game kicking counts, for example Gary Anderson's 1998 log.
- NFL-hosted `static.www.nfl.com` game summary PDFs include scoring plays, field-goal distance summaries, extra-point outcomes, and NFL copyright/source notices.
